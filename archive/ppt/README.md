# Presentation Archive

This directory keeps local presentation sources and rendered review images that
are not part of the RCA runtime or paper experiment pipeline.

- `source/`: original PNG assets and the editable PowerPoint deck.
- `rendered/paper/`: rendered manuscript pages used for visual review.
- `rendered/pdf/`: rendered PDF pages used for visual review.
- `introduction大纲.md`: the retained presentation outline.

Binary files under this directory are intentionally ignored by Git. They remain
available in the local workspace; previously tracked versions can also be
recovered from repository history before the RCA cleanup.
