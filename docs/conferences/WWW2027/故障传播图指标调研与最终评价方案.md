# 故障传播图指标调研与最终评价方案

日期：2026-09-10。适用范围：本篇 WWW 单根设备级传播 DAG；P0 为主方法，P4 单列为优化实验。本文完成指标选择和评测协议设计，**没有修改评测代码、人工标签或产生新的性能结果**。协议版本建议记为 `graph-eval-v2`；在实现和标签审计完成前，不能把现有结果改名为 v2 结果。

## 1. 决策与适用范围

主任务是恢复一次 Pingmesh 异常中有证据支持的设备传播结构，回答“从哪个源头，经由哪些设备关系，形成了哪些影响”。它不是恢复真实 ECMP 转发路径，也不是恢复一个可直接计算干预分布的完整结构因果模型。物理邻接、时间先后和告警同现分别只能支持候选关系；评测不能把这些约束满足率当作传播真值准确率。

冻结以下指标组合：

| 层次 | 核心指标 | 用途 |
|---|---|---|
| 固定根图恢复：Oracle、Shared 分表 | 案例宏平均有向边 P / R / F1；完整图标签子集的 Exact-Graph | 验证直接传播关系恢复，不被根排序混淆 |
| 自主完整流程：Full | 最终根 Top-1、普通有向边 F1、Joint-Edge-F1；完整图子集 Joint-Exact | 同时揭示根是否正确、图是否有用；联合指标防止错根而局部边碰巧命中 |
| 必报诊断 | 节点 F1 与去真根节点 F1、失败/弃权/适用覆盖、未知输出、raw/等价投影、图规模分层、结构合法性 | 解释分数来源与适用边界 |
| 完整标注子集辅指标 | SHD-1、祖先可达关系 P / R / F1 | 区分局部方向错误与多跳连接损坏 |
| 有连续边分数时的消融 | 已判定候选边 AP、F0.5、方向/No-Direct 混淆 | 分析边打分和保守阈值，不替代最终解码图 F1 |
| 不作为当前主指标 | SID、无条件全图 GED、AUROC/全邻接 accuracy、加权“相似度≥0.8”、单独 coverage | 或语义不符，或掩盖稀疏性/空图/任意权重问题 |

**完整图与部分标注分表报告**。若完整且经复核的标签不足，主实验只能声称“已判定范围内的传播关系恢复”，不能称全图恢复率。规范标签、同一输入清单、相同事故分组和同版评测器，比再添加一个图指标更优先。

## 2. 一手来源与选择依据

下表来源均于 2026-09-10 在线核验。指标基础文献不受近三年限制；近三年 WWW 契合度调研是另一项任务。本节只陈述来源支持的事实；下文的 mask、联合指标和分母规则是本项目的评价设计，不冒充这些论文的原始协议。

## 3. 冻结评价对象和标签语义

### 3.1 事故与候选域

每个案例 i 固定：事故组 `group_id`、观测截止时间、原始拓扑 T_i、共同设备全集 C_i、输入指纹、人工标签版本和任务范围。不同方法收到同一份观测，不能因某方法只返回几台设备就缩小评测域。

图真值写作 G_i*=(V_i*,E_i*)，预测为 Ghat_i=(Vhat_i,Ehat_i)，有向边是有序对 `(u,v)`，节点身份固定。节点集必须显式保存，不能仅取边端点：确认单根且没有跨设备传播时，合法图为 `{r*}` 加空边集，不能丢掉孤立根。

主实验先按独立标注证据划分确认单根、根仍不确定、确认多根、链路根及范围外案例。后三类不强行取标签数组第一台设备放进单根正确率；总清单保留数量与原因。多根扩展继续挂起，不在本协议中暗中改变任务。

### 3.2 五种关系状态

令 U_i={(u,v):u,v∈C_i,u≠v} 为共同有向设备对全集。物理邻接候选 U_i^T 是其子集；打分器只对物理候选打分可以，但评价的真值域不随模型输出缩小。

| 状态 | 记号 | 计分 |
|---|---|---|
| 已确认存在的直接传播 | E_i+ | 需要预测；漏掉计 FN |
| 已确认不存在该方向的直接传播 | E_i− | 预测计 FP |
| 允许但不要求的边 | A_i | 中性：出现和不出现都不奖惩 |
| 尚未判定 | U_i \ (E_i+∪E_i−∪A_i) | mask，不计 FP/FN |
| 全图已经完整检查 | `graph_complete=true` | 明确正节点/正边以外均负；不允许仍有可选或未知图关系 |

规范字段沿用 `positive_edges`、`known_edge_mask`、`allowed_edges`。实际计分 mask 为 M_i=`known_edge_mask \ allowed_edges`，且 E_i+⊆M_i。新转换器应拒绝正例与 allowed 重叠、mask 外正例、矛盾方向语义、节点 ID 域外、正边端点未包含在确认正节点等不一致标签，不能静默纠正。

`possible` 不能按字符串机械变成正例：工程师需判断它表示“已确认的替代完整假设中的必要边”“可选允许边”还是“未知”。`No Direct` 是该设备对没有直接传播，不等于没有间接可达路径；`A→B` 已确认也不能在未明确单向语义时自动标 `B→A` 为负。

节点有独立正集 V_i+ 和 mask M_i^V，不能由边 mask 推断节点完整度。只有已知负例而无正边的局部范围称“已判定无边范围”，不冒充整张图为空。

### 3.3 多个可接受解释

主表先使用无歧义完整图或显式部分标签。若工程师确认若干互斥完整假设 H_i={(r_h,V_h,E_h)}，另设“集合值标签”分层：

- Joint-Exact 需预测根、节点、边同时匹配**同一个** h；不能根取假设 A、边取假设 B。
- 图相似度可报告 `max_h F1(Ghat,G_h)`，明确它是“对可接受集合的最佳一致度”；所有伴随节点/结构指标绑定同一个选中 h，固定并披露打平规则。
- required/allowed 表示的是一族可接受图，allowed 不变成 required；不同假设的相反边不取并集。
- 当前公共 baseline schema 尚无完整的 H_i 表示；实现前不把 legacy `acceptable_hypotheses` 转成完整 exact 标签。

## 4. 主指标公式、空集和分母

### 4.1 有向边 P / R / F1

完整图：Phat_i=Ehat_i；部分标注：Phat_i=(Ehat_i∩M_i)。令 P_i=E_i+，则

\[
TP_i=|\widehat P_i\cap P_i|,\quad
FP_i=|\widehat P_i\setminus P_i|,\quad
FN_i=|P_i\setminus\widehat P_i|,
\]

\[
P_i^{edge}=\frac{TP_i}{TP_i+FP_i},\qquad
R_i^{edge}=\frac{TP_i}{TP_i+FN_i},\qquad
F1_i^{edge}=\frac{2TP_i}{2TP_i+FP_i+FN_i}.
\]

反向预测 `B→A` 对真边 `A→B` 造成一次 FP 和一次 FN，前提是两个方向都在已判定范围。只知 `A→B` 为真而反方向仍 unknown 时，漏真边仍计 FN，反方向输出单独记 unknown。

每一列附 `n_scope_cases / n_total_cases`。宏平均为 `sum_i score_i / n_scope_cases`，先计算每例 F1 再平均；它不等于宏 P、宏 R 的调和平均。主表不按图边数量加权。补充 micro P/R/F1 可合并 TP/FP/FN，但它会偏重大图，且不能充分惩罚在零正边案例上发生的运行失败，因此不能替代主表。

### 4.2 空集、失败与缺标

与新公共评测器的成功案例集合得分约定保持一致，并单列零边分层：

| 情况 | 边 P / R / F1 | Exact / 解释 |
|---|---|---|
| 成功；可评范围内真边非空、预测空 | 0 / 0 / 0 | 不正确 |
| 成功；可评范围内真边空、预测非空 | 0 / 1 / 0 | 局部或完整已确认范围的假阳性 |
| 成功；可评范围内真边空、预测空 | 1 / 1 / 1 | 仅表示该已判定范围无边；完整 Exact 还须节点相等 |
| `runtime_failure`、`input_ineligible`、明确 `abstained` 或图输出失败 | 有可评标签时均为 0 | Exact=0；保留在该任务分母 |
| 没有任何可评边范围 | N/A | 不因两个空集给满分，不编造 0 分真值 |
| 完整确认无边图，根节点缺失/错误 | 边 F1 可为 1 | 节点/Exact/联合指标揭示错误；因此不能只报边 F1 |

`unknown` 预测被 mask 后可得到很高的局部 F1，这并不说明整图可靠；必须同时报告第 6 节的未知输出。完整零边、非空边案例各报数量和 F1；至少另列非空真图 F1，避免系统靠常输出空图获益。

冻结清单里“预测缺一条记录”是运行完整性错误，先补明确失败记录或修复导出，再评分；不可从分母删掉。无标签案例留在执行覆盖/失败统计，仅从依赖真值的那一列排除，并披露 `n_label_unavailable`。

状态须分开：`run_status`、`root_status`、`graph_status`、`diagnosability`。程序运行成功却图生成失败，应令图指标失败；成功输出部分图同时标 `unidentifiable` 不自动视为弃权，除非接口确实拒绝交付图。状态转换规则在评分前固定。

### 4.3 Exact、联合指标和根排序

完整图标签下：

\[
Exact_i=\mathbf1[graph\_success_i\land\widehat E_i=E_i^*\land\widehat V_i=V_i^*].
\]

Full 的原始设备根正确指示 c_i=1[根预测成功且 rhat_i=r_i*]：

\[
JointEdgeF1_i=c_i\cdot F1_i^{edge},\qquad
JointExact_i=c_i\cdot Exact_i.
\]

联合指标仅对“确认单根且有相应图标注范围”的清单求均值。Joint-Edge-F1 不是本文新发明的图距离，而是公开写明的端到端成功效用；与普通 F1 并报，显示根失误造成的代价。部分标签的联合指标明确标 `Masked-Joint-Edge-F1`，不称全图正确率。

Stage-1 单独报告 Top-1/3/5、MRR、共同候选设备域的真根覆盖、实际返回 Top-K 的真根覆盖；失败或未返回真根时 rank 贡献为 0。Full 的最终根 Top-1 另报，不用 Stage-1 的 MRR 代替最终选择效果。Shared/Oracle 的根由外部给定，根准确率应标“输入条件”，不能写成该图方法的能力。

节点 P/R/F1 采用同样集合定义和独立 mask，包含显式根节点；额外报告去真根节点指标，即从预测/参考节点及对应 mask 中同时移除 `{r*}`。这样错误预测根仍会被计为多余节点；该辅助指标只用于真根已确认的案例，并明确它与代码 `node_without_root` 的语义一致。

## 5. Raw 与结构等价评价

保留当前论文的“无已记录区分观测的精确结构同类节点”投影，但**等价指标与 raw 指标必须同时可见**：主图表可使用等价视图，紧邻表格给出 raw Edge-F1、Raw-Exact 与投影规模；不得只发布提高后的等价分数。

映射 phi_i:C_i→C_i/~ 只由相同原始拓扑、拓扑角色/故障域、端点以及所有方法共同可见的原始观测构造。两台内部设备需满足精确上下游集合相等；无可靠方向时使用精确无向邻居集合。已有设备证据、受保护端点不合并。规则、输入窗口和版本预先冻结。

它是本项目的**结构与观测区分粒度约定**，不是因果发现中的 Markov 等价类，也不证明两台设备在物理上具有完全相同故障行为。不能因模型失败而放宽聚合条件，不能利用真实根/传播标签决定聚合，不能按各方法 Top-K 分别建映射。真实根正确率始终按原始设备 ID 计算；任何根等价命中率只能另列。

预测与标签应用同一 phi，边去重并去投影自环，显式节点同步投影。必须记录每例 raw/投影节点边数、聚类数量、受保护节点、合并成员数、折叠自环数与重复边数。原始图和投影图各检查合法性；投影后正确不能隐藏原始非法边或过多路径。

**部分标签的 mask 不能简单把所有已知负边投影后取并集。** 对虚拟边 q，设 F(q)={e∈U_i:phi(e)=q}，使用“类间至少存在一条传播边”的语义：

1. 若 F(q) 中有确认正边，则 q 为正；
2. 若没有正边，且 F(q) 中每一条可能对应的 raw 边均被确认负，则 q 为负；
3. 若仍有 unknown 或允许边，则 q 不进入二元负 mask；保留 unknown/allowed 诊断。

节点类也采用“任一成员为正即类为正；全部成员确认负才为负”的规则。原始非物理边只有在任务规范/标签审计已明确将其纳入负域后，才可帮助判定类级负例。重复边在投影后只算一次；因此不能直接对 raw TP/FP/FN 做相加得到投影分数。

例：并行设备 A1/A2 映射为 A，A1→B 已知不传播、A2→B 未判定，则 A→B 仍未知；把前者的负标签投影为 A→B 负，会错误惩罚经过 A2 的解释。若 A1→B 已确认传播而 A2→B 已知负，类级 A→B 为正；raw 视图仍能区分选错了哪台设备。

## 6. 辅指标与工程诊断

### 6.1 结构差异与多跳关系

**SHD-1：只在完整图标签且同一节点全集上评价**，孤立设备补入同一候选节点序，不做任意节点重命名。对每个无序设备对，其状态属于 `无边 / u→v / v→u`；状态不一致计 1。因此缺边、额外边、单次反向各计 1，SHD-1 为总和。双向/自环等非法输出单列；不悄悄转 DAG 后再说是原生 SHD。完整有向图的 `FP+FN` 是另一种反向计 2 的量，若报告则命名 `Directed-SHD-2`。

SHD-1 给出案例均值和分布，图大小分层；不把 `1−SHD/|E*|` 称“准确率”，它可能为负且零边分母无定义。节点错误由节点 F1 单独衡量。部分标签暂不扩展 SHD，防止缺少反方向标签时把未定状态算错。运行失败的距离记 N/A，绝不记成表示完美的 0；SHD 表明示这是成功且满足图格式的案例诊断，附失败/非法输出数，方法差异只在同一个共同成功子集上比较，并由全清单失败效用主表约束解释。

**祖先可达关系 F1：** 对完整参考图，定义 A(G)={(u,v):u≠v，G 中存在 u 到 v 的有向路径}。比较 A(Ghat) 与 A(G*) 的 P/R/F1；raw 与等价视图各自先得到完整图再计算传递闭包。空集规则与直接边相同；运行失败为 0。

它检查多跳连接是否保留，但只要首尾仍可达，路径不同也可能得分相同，不能称“Exact Path Recovery”。例如真图 A→B→C 与预测额外加 A→C 的可达集合相同，直接边 precision 能揭示多余捷径。两者配合，不用可达指标替代直接边指标。

部分边标注不能直接取 E+ 的传递闭包后把其它可达对当负。只有另有已审查的可达正/负 mask，才可做 masked reachability；在此之前只在完整标签子集报告。根到症状的可达率可作操作诊断，但在所有节点均根可达的图里容易退化成节点覆盖。

### 6.2 不确定范围、合法性与规模

每例及总体报告：

- 已判定边范围 `|M_i| / |U_i^T|`（分别声明统计域；若 M 包含非物理对，先取交集），已确认正边数、明确负边数、allowed 数、unknown 数；节点同理。完整/部分标签、标注者及抽样方式单列。
- 未知输出数 `|Ehat_i \ (M_i∪A_i)|` 及占预测边数的比例，allowed 输出数、已评分预测比例。空预测的比例记 N/A 并给计数 0，避免把“什么也没交付”解释为充分可判定。
- 原始物理边匹配率、DAG 率、根入度为零、节点域合法率、根可达率、原始证据引用可解析率。每条物理匹配需能回溯 `task_topo` 原始边 ID；仅有同端点配对还不足以验证证据链。
- 成功空图的 DAG/物理匹配可按真空成立记 1，但另报非空输出上的合法率与分母；无输出失败的操作有效率为 0。时间兼容、症状覆盖、证据 ID 非空只叫约束/追溯诊断，不能叫 causal accuracy。
- 预测与参考节点/边数、非空参考的 `|Ehat|/|E*|`、空图输出率；完整参考图按零边、单边、多边单链、存在分支/多父关系分层，类别规则互斥且预先固定。另报图深度、原始候选规模与可观测设备比例。

当前设备图可有多个父节点，不能为了使用树编辑距离先强制剪成树。一般 GED 的自由节点匹配会把设备身份错配隐藏掉；本任务固定身份、有向边集合与 SHD 已能提供较清楚的错误含义，暂不引入任意 GED 成本。

### 6.3 边分数、保守输出与弃权

在同一冻结候选边域及已判定二元标签上，候选打分器可报告 AP：`sum_t (R_t−R_(t−1))*P_t`。无正边案例的 AP 记 N/A 并报告数量；只具有正边、没有已判定负边的案例不能支持判别能力结论。AP 用于解码前排序，最终图仍需固定训练侧阈值再算 F1。不同方法若没有可比较完整分数，不补造分数凑 AP 主表。

F0.5=`1.25*P*R/(0.25*P+R)` 可用于 P4 的精度优先阈值选择和边级消融；它不能自动成为全部图方法的唯一主指标。F1/F0.5 差异应反映漏边与误加边代价取舍，不用已看过的测试集选择最有利 beta。

若系统能真正接受/拒绝输出，对开发集冻结的阈值 tau 报接受覆盖 `N_accepted/N_scope` 和接受案例上 `mean(1−EdgeF1)`；完整标签可加 `1−JointExact` 风险。它们是结构损失的经验 risk-coverage 曲线，不是理论风险保证。主表仍计入拒绝案例的失败效用，避免只展示少数简单案例的高质量。

若要声称帮助工程师排障，后续单独测人工检查设备/边数量、完成任务用时、漏查或错误动作率；当前图规模、可达或 F1 都不能直接折算为 MTTR。

## 7. Root / Oracle / Shared / Full 的公平实验设计

| 设置 | 根来源 | 比较内容 | 禁止混淆 |
|---|---|---|---|
| Root | 方法自身排序 | Top-K/MRR 与候选覆盖 | 不给只输出图的方法臆造根排序 |
| Oracle | 确认单根 r*，仅由外层控制器提供 | 根正确条件下的图恢复 | 是受控诊断，不是可部署成绩，也不是任务理论上限 |
| Shared | 同一个冻结的 Stage-1 OOF 预测根（或同一 Top-K 协议） | 固定真实会犯错的上游根条件，比较图模块 | 不允许某法用真根、另一法用预测根；不按图质量选择根 |
| Full | 每个方法自己的预测根和正式选择流程 | 原生可部署流程的最终根、图与联合质量 | Root-only 方法不补一个本文图模块后冒充其原论文 Full |

所有设置使用同一案例清单、观测窗口、候选域、原始输入版本和 incident-group 外层折。训练监督额度列明：根标签、事件根标签、边标签、无监督逐例拟合不能混写。根输入只在 Oracle 的包装层使用，是唯一明确的测试标签注入控制；传播标签始终只在评测器使用。

对 NEC、PCMCI+、DYNOTEARS 等事件/时间变量原生图，统一保存 `native graph → raw device projection → final adapted graph`。当前 `device_greedy_v1` 采用设备映射、同设备折叠、多支持取最大、删非物理/入根边、确定性去环和根可达裁剪，保留多父结构且不发明新边、路径或未定方向。每一步损失均需保留；最终图的高合法率部分来自共同适配约束，应同时给出适配前合法性和边保留率。

原生模型不因 Oracle 真根重新拟合；公开适配器可以消费给定根，但所有参照方法必须获得同等条件。P0 本身根条件解码是待比较的方法设计，不能偷偷作为外部方法的共同适配器；如试验“某原生分数 + P0 解码”，必须另行命名，列为组件组合实验。

时间序列方法仍须先通过采集覆盖、有效长度、时间变化与输入语义审计。报告两张表：全任务清单上的适用率/失败效用，以及**在运行前由输入条件确定的共同适用子集**上的配对质量。不依据预测是否成功/准确来选择该子集；同时给成功例质量作诊断。无法接入的方法标 N/A，不虚构其完整流程或用补零绕过输入门槛。

既有 2026-09-08 记录已包含 Candidate Oracle 和 Direct Oracle，不能重复列为“尚未做过”。它们下一步是按冻结新标签/协议统一重评分；若根标签、观测或模型版本变化，再重新生成预测。Candidate Oracle 仍受候选覆盖限制，必须保留未召回案例，而不是只算 201 个成功案例。

## 8. 事故分组、置信区间与版本

主结果采用案例宏平均；真实事故组作为划分与不确定性抽样单位。一个事故的多个 Pingmesh 任务、告警窗口和设备样本必须同组。不能用 case_id 自动冒充已核实的事故组。

固定一次外层 grouped-OOF 生成每例恰好一份测试预测；词表、归一化、校准、阈值、超参及图重排权重只从相应训练侧/内层验证组产生。不得在 held-out incident 上选边阈值或挑等价规则。若历史全部案例已多次参与方法选择，称回顾性开发验证；新时间段/站点的冻结案例才能支撑更强独立泛化声明。

95% CI 使用预先固定种子、10,000 次事故组 bootstrap：每次有放回抽取与原始相同数量的组，整组携带全部案例，再重算同一宏平均。这样仍以案例为点估计单位，组内相关性不被拆散；额外可列每组先平均后的“事故等权”敏感性结果，二者名称分开。

方法差异使用相同案例和**相同重采样组索引**计算 Delta=score_A−score_B，报告配对差值及 2.5%/97.5% 分位区间；不能看两组各自 CI 是否重叠来替代差异分析。指标适用清单也须相同，方法失败不得从配对中排除。执行固定种子只是可重复性选择，不是显著性保证。

每列附样本量、已核实组数和组大小分布。少于两个可核实独立组或分组未知时 CI=N/A；仅满足两个组也不代表区间稳定，组数少时应将结论保留为描述性。该 bootstrap 不涵盖重新训练带来的全部随机性；若报告训练稳定性，单独给固定数据划分下的多种子结果。

随结果冻结：输入/标签/模型/评测版本与哈希、fold manifest、共同根文件、等价映射版本、适配器版本、阈值来源、输出状态、每例 TP/FP/FN、所有分母、原始图和适配图。任何标签/计分修订先对同一旧预测重评分，将“评测修正”与“算法改变”分开。
