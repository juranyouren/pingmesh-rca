## Understanding

目标是单设备根条件下的事故设备传播解释 DAG。须分开评价设备关系、根定位与检查工作量。
解释图不是已识别的干预因果模型，指标不能补救真值语义或独立性缺失。

**建议有向边 F1（附 P/R）；完整参考图合格时再加 raw SHD-1。**
F1 衡量相对匹配程度，SHD 给绝对编辑错误量和不同反向权重；不是“局部＋全局业务指标”。
部分标签时第一项只代表已判定域；第二项仍依赖完整子集，不能宣称当前已有两个可运行指标。

### 3. F1 与 SHD 的增量信息：最小手算

以下是本项目数学说明。固定设备身份和完整有向边域，无自环、无双向边。
真边 E、预测 Ê；TP=|E∩Ê|，FP=|Ê−E|，FN=|E−Ê|。
P=TP/(TP+FP)，R=TP/(TP+FN)，F1=2TP/(2TP+FP+FN)。

反向一条边贡献一次 FP 和一次 FN。SHD-2=FP+FN；SHD-1=FP+FN−r，r 为反向边数。
分母非零时 F1=1−(FP+FN)/(|E|+|Ê|)。SHD-1 新增绝对错误量和反向权重，没有多跳业务语义。

| E；Ê | TP,FP,FN,r | F1 | SHD-1；SHD-2 |
| --- | --- | --- | --- |
| {a→b}；{b→a} | 0,1,1,1 | 0 | 1；2 |
| {a→b,b→c}；{a→b} | 1,0,1,0 | 2/3 | 1；1 |
| {a→b,b→c,c→d,d→e}；{a→b,b→c} | 2,0,2,0 | 2/3 | 2；2 |
| {a→b,b→c}；{a→b,c→b} | 1,1,1,1 | 1/2 | 1；2 |
| ∅；{a→b} | 0,1,0,0 | 0 | 1；1 |
| ∅；∅ | 全零 | 需约定 | 0；0 |

同 F1 可有不同绝对错误量；同 SHD-1 可有不同 F1。raw SHD 在零边真图上有定义，除以 |E| 才失效。
真链 a→b→c→d 分别删 a→b 或 b→c：都 F1=4/5、SHD-1=1，但损失可达对分别 3 和 4。
相同边集必有相同可达关系；相同分数不必。完整简单 DAG 下邻接 F1 与有向 F1 之差是
2r/(|E|+|Ê|)，不是反向边数 r。可达 F1 暂为本文辅助提议，没有核实到高度匹配的通行采用依据。

### 4. SHD 对照已修正

[锁定版本的来源表](sources.md#2-shd-实现证据锁定版本)区分接口和图类型。
causal-learn 的 SHD 比较无序节点对端点，反向计 1；ArrowConfusion 是另一种度量。
CDT/dodiscover 的 1/2 来自参数；SHD_CPDAG 先转换图不是自相矛盾。
gCastle 无向预测边的骨架信用不等于反向边计零。bnlearn 5.3-20260901 默认 CPDAG，另有 cpdag=FALSE；
旧 5.0 文档不能排除全部版本。本项目若采用 SHD，须声明固定节点、完整 DAG、增删反向单位代价。

## Recommendation

### 完整标签条件

主项有向边 F1（附 P/R），辅项 raw SHD-1；按设备数和真边数分层，披露样本数。
事故宏平均是本文选择，不归给未说明口径的文献。逐事故 F1 的平均不等于平均 P/R 的调和平均。
微平均可作规模敏感性对照。双方空图建议 F1=1 并单列数量；仅一方有边 F1=0；
分母为零的 P/R 标 NA。这些是待冻结的项目约定，边指标不能评价显式孤立节点或根正确性。

### 部分标签条件

在与方法无关、预先冻结的已判定有序关系域 D 内比较 E∩D 与 Ê∩D。
unknown 未判定、allowed 中性、possible 待澄清；均不能自动当负例。
披露抽样方式、已判正负数、unknown 比例、预测域内覆盖及未评分预测数。
仅有正例时，precision 不具有完整误报解释；分数不得称全图准确率。
域外预测应另报并考虑独立盲审，防止把预测移出 D 就看似改善。
完整 SHD、exact-match、可达评价需完整合格子集；当前标签与 mask 资格仍 UNKNOWN。
A4 的“架构上已知存在但窗口没流量”与未知真值不同，不支持上述掩码规则。

### 排查收益条件

优先报告预算成功率、动作 Q、不同设备 N。静态逐台完美确认且根在全列表时 N=rank(root)。
等成本每设备一次时 T=cN；推理时间、模拟确认时间、真人诊断、真实缓解分别报告。
见 [排查设计](troubleshooting_evaluation_design.md)：固定初始根排序、输入、反馈和预算，比较无图/原始拓扑/预测图。
