## 2. 统一实验口径

- **Root**：SkyNet、BiAn、NEC。评分包括 Top-1/3/5、MRR、候选覆盖、返回覆盖和失败率。
- **Oracle 图**：NEC、PCMCI+、DYNOTEARS。只有包装层取得确认根；外部方法的原生图不随真根更换。
- **Full**：本轮只开放 NEC；使用自身预测根加共同设备适配，报告联合边 F1/联合整图正确。
- **共同预测根图**：显式 `--task shared --roots ...`；用于固定另一方法的预测根，不能与 Oracle 混写。

图统一经过 `device_greedy_v1`：原生节点映射设备、同设备折叠、多支持取最大、去非物理边/入根边、按支持度与 ID 确定性去环、保留根可达部分。保存原生图、未经筛选设备投影、最终图及每步损失；保留多父节点，不发明方向、路径或边。适配前后合法性分别记录。

未知标签范围不会被当成负例；允许边为中性；完整标签才算 exact graph。没有已知标注范围时不给空集满分。失败、弃权和输入不合格案例保留，另报成功例质量。置信区间须有经核实的至少两个事故组。输入哈希不匹配、标签/预测清单缺例、跨组泄漏都会拒绝。

NEC 的词表、工程先验和模型只从训练组学习，验证 NLL 用于选择 epoch。公共 runner 目前执行固定配置，没有实现自动超参搜索。PCMCI+/DYNOTEARS 每事故无标签拟合，开销算入推断；不能与跨案例训练方式混写。

## 3. 实际验收证据

环境：Windows、Python 3.12.10、PyTorch 2.14.0+cpu、NumPy 2.5.3、SciPy 1.18.1、Tigramite 5.2.10.1。全部依赖固定在 `Baseline/requirements-repro.txt`，运行环境位于忽略的 `tmp/baselines-venv/`。

执行的新测试与相关旧入口回归测试合计 **95 项通过，0 失败、0 错误、0 跳过**。原始 JUnit 记录 `tmp/baseline-validation/pytest.xml`；机器可读总记录 `Baseline/validation_report.json` 保存版本、代码/产物 SHA-256 和状态数量。

| 验收 | 实际结果 | 证明范围 |
|---|---|---|
| 公共协议测试 | 29 项通过 | 白名单/端点数组、时间单位/截止/零占位、静默节点、schema、分组、mask、失败分母、图适配与 CLI |
| NEC 单项测试 | 15 项通过 | 解析积分与梯度、RK4、空历史正则、IG 完整性、严格过去、同时事件、检查点、未知类型、失败重训 |
| BiAn 单项测试 | 26 项通过 | 注入响应的三流程执行、三轮聚合、超过六个候选、证据/预算/错误处理、标签替换不改变请求 |
| SkyNet 单项测试 | 11 项通过 | 手算票数、去重、未知对端、不扩大邻域、静默设备与弃权 |
| PCMCI+/DYNOTEARS 单项测试 | 10 项通过 | 真正数值拟合、滞后方向/负系数/自回归、未定向同期边、作者 W/A 一致性、收敛失败与 coverage 门槛 |
| 旧入口回归 | 4 项通过 | 既有 baseline 路径和 BiAn Pipeline1 入口继续工作 |

BiAn 的测试 transport 仅为契约测试，不算模型实验。另执行了真实 HTTP 检查：默认 `127.0.0.1:8000/v1` 返回服务不可用/超时的 `runtime_failure`，排名为空，没有 fallback。记录在 `Baseline/BiAnAdapt/validation/local_backend_smoke.json`，使用公开合成观测。

NEC 统一 CLI 在 **6 个人工接口案例、3 个外层折**上真实训练并保存 3 个检查点，Full 输出 6/6 `ok`；从第一折检查点加载，仅对该折 2 个测试案例执行 Root 和 Oracle，各 2/2 `ok`，并完成独立评测。每份输出通过公共 prediction schema。产物在 `tmp/baseline-validation/synthetic/`。

这些合成案例用于运行契约与机制检查，不能证明根定位/传播质量。NEC 的 A→B→A 检查包含人工设置参数以验证方向，也不等于学习恢复该机制。没有据此报告真实 Top-1、F1 或显著性结论。

## 4. 本机数据接入结果

目前可见 2 个 raw 文件，`data/node` 没有全量案例。采用统一触发窗口前后各 300 秒后：

| 案例 | 候选设备 | 物理边 | 窗口内告警 | 实际日志行 | 已知采集时间 |
|---|---:|---:|---:|---:|---:|
| 第 1 例（按 task_id 排序） | 22 | 16 | 2 | 0 | 0 |
| 第 2 例 | 11 | 13 | 12 | 0 | 0 |

每例各有 1 条告警在固定窗口外。alarm_time 为毫秒时间，occur_time 为 0 占位，按缺失处理。log_list 只有 total，不制造逐条日志。task_trace 不作为精确路径使用；cross 与标签对象不进入方法输入。详细映射见 `Baseline/common/raw_to_input_mapping.md`。

SkyNet 在两例上实际完成 Root 投票输出（2/2 `ok`）。两个时间图方法对同一清单运行，均为 2/2 `input_ineligible: collection_coverage_unknown`，没有通过补零绕过门槛。单例产物与审计保存在 `tmp/baseline-validation/raw-*.json`。

raw 样例没有经核实的事故分组，也尚未转换为本轮明确语义的图标签。未用这些样例训练 NEC 或生成正式性能表。
