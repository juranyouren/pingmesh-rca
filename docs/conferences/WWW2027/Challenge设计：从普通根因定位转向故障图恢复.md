# Challenge 设计：从普通根因定位转向故障图恢复

更新：2026-09-10。范围：单设备起点、incident-specific 设备传播解释 DAG。这里的传播是受观测支持的影响假设，不是已识别的干预因果图。

## 1. 修改结论

删除“设备多、事件混杂，因此根因难找”作为独立创新挑战的主表述。这些是普通 RCA 已长期处理的问题。第一个挑战改为：**不确定起点与可恢复传播结构相互耦合，根排名本身不足以保留图恢复需要的解释空间。** 这是一项面向输出图的任务要求；Top-K、根条件化或反馈重排本身仍不是首次提出的技术。

新主线：C1 决定保留哪些起点—图假设；C2 判断相邻设备的直接关系；C3 选择能够在一次 incident 中共同成立的结构。C1 讨论上游不确定性，C3 讨论给定起点后的组合一致性，避免重复。

## 2. 可以直接进入稿件的三个挑战

### C1：起点不确定性会改变可恢复的传播结构

设备传播图中的起点决定哪些节点需要从同一来源得到解释，以及哪些方向能够构成根可达的结构。因而，根定位误差不仅改变设备排名，也可能在图恢复开始前排除正确的传播方向和分支。以物理相邻的 C、S 为例，在静态单根模型中，分别以 C 和 S 为起点会对 C→S 和 S→C 施加不同的结构条件；即使参与设备完全相同，也对应不同解释。不完整事件可能不足以先确定唯一起点，但图合法性也不能反过来证明某个起点正确。挑战是在可控代价下保留图恢复所需的起点假设，使候选结构能在相同观测和局部证据下比较，并明确哪些部分仍无法区分。

### C2：不完整旁证不能直接给出设备关系和方向

在给定起点之后，仍须判断相邻设备是否在本次 incident 中直接影响彼此。接口与 peer 信息、告警语义、记录时间和物理邻接提供不同强度的支持，却不等于直接传播的观测；同时发生的事件可能具有共同原因，缺失的事件也不等于已确认无传播。挑战是区分方向支持、反向支持、无直接影响证据与未知信息，保留冲突，而不是先将旁证硬化为边。

### C3：局部得到支持的关系未必组成一致的整体解释

独立选择设备对的方向可能形成环、与假设起点断开的片段或缺少证据的分支。即使图合法，仍可能无法解释某些异常设备；结构缺口不能靠最短物理路径自动填补。挑战是在给定起点的条件下组合证据支持的关系，满足明确的结构约束，并同时保留替代解释与无法覆盖的部分。静态 DAG 和距离递增是本文的建模限制，不代表实际网络影响必然没有反馈、横向影响或绕行。

## 3. 根因定位在本场景的特殊要求

设观测为 O、原始拓扑为 T，根排序输出 q(r | O,T)。图恢复需要的是候选对 (r,G)，其中 G 属于在该起点和建模规则下允许的结构集合 F(T,r)，且每条输出边都仍需局部证据。

早期 Top-1 只探索 F(T,r1)；保留 K 个起点可探索这些集合的并集。但并集扩大不保证包含真实图：候选根可能全错，局部证据可能缺失，距离递增规则也可能排除合法标注边。不能将“更多假设”写成“解决可识别性”或“保证正确”。

| 普通排序评价能回答什么 | 图恢复还需要什么 | 对应检查 |
|---|---|---|
| 真根是否排在首位 | 候选集合是否保留可用起点 | Top-K recall 与 K–计算开销曲线 |
| Top-1 错在哪台设备 | 起点变化丢失/翻转哪些关系 | 同观测、同局部支持，固定不同根的配对图比较 |
| 根概率是否有区分度 | 没有足够图证据时能否保留备选 | 备选数量、覆盖率、拒答/失败分桶 |
| 图评分是否改对根 | 图评分是否用错误结构改坏根 | root correction/corruption；固定 Top-1 与图重排分开 |
| 给真根后定位不会错 | 给真根后图是否仍恢复失败 | 直接 Oracle 根图、结构规则召回上界 |

## 4. 与方法的一一对应

M1（PC-STGR）提供有限的竞争单根起点；M2（P0 局部支持）在原始相邻设备上构造可复用支持；M3（P0 结构组装）逐根选择路径并合成 DAG。实现仍是 Stage 1 = M1，Stage 2 = M2 + M3；这些概念模块与代码目录中历史 `m1/m2` 名称不是同一编号。

M1 单独不能解决 C1，C1 需要 M1 保留假设并由 M3 给出条件结构。图评分是否覆盖原始根排名应按已冻结实验配置说明，不能把尚未实现的可靠拒答策略写成已有保障。M2 的归一化支持不称为校准因果概率；M3 的根距离递增约束强于一般 DAG/根可达性，且不保证全局最优。

## 5. 最小证据闭环与反证条件

| 实验 | 固定项和变化项 | 支持论点的结果 | 不能得到支持时的处理 |
|---|---|---|---|
| 起点误差与图误差 | 同数据、同 M2/M3；比较冻结预测根和直接真根 | 图差异显示误差受起点影响 | 若几乎无差异，弱化 C1 的工程重要性 |
| Top-1 与 Top-K | 相同训练、同图构建；仅改变候选范围 | 候选覆盖与图质量/代价出现可解释取舍 | 只有 root recall 改善不够支撑图收益 |
| 固定根与图重排 | 使用相同候选条件图，改变最终选择 | 同时报根改对/改错与图质量 | 若图重排改坏根，将其列负结果，不预设收益 |
| Oracle 结构上界审计 | 真根及冻结拓扑规则，检查标注边可进入率 | 揭示距离规则和候选剪枝限制 | 规则排除大量标注时先修问题定义/规则 |
| 观测删减 | 同一事故组内受控删减，不借用删掉证据 | 区分根/边/覆盖受影响程度 | 只能说明该删减机制，不能等同真实所有缺失 |

`candidate oracle` 只能在已有 Top-K 内使用真根，不能替代直接提供确认根的 `direct oracle`。Oracle 是诊断控制，不是部署输入。本文不运行新一轮训练，不预填表格数值。
