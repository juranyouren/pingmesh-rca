> 现改为「按已核查范围给出的重要精读候选」，并撤回不成立的推论。

### 6.1 重要精读候选（已读全文，非排名）

1. **PropLLM**（arXiv:2606.00582）——逐跳回溯传播路径 + 拓扑因果先验；
   依赖**作者自建的双层知识图谱**；输出**一条因果链**；未报告图结构指标。
2. **EvoCause**（arXiv:2607.27290）——LLM 引导演化的**告警传播图（APG）**；
   节点是**告警类型**；**TeleRCA 无传播图真值**，图指标（Graph F1 / nSHD）
   **只在合成 DAG 上报告**。

两者的详细核对与撤回项见 [papers/RW0106.md](papers/RW0106.md)、[papers/RW0104.md](papers/RW0104.md)。

### 6.2 已撤回的推论

| 原表述 | 处理 | 理由 |
|---|---|---|
| 「EvoCause 说明对告警因果图打分在该社区已有被接受的指标口径」 | **撤回** | 其图指标**只在合成数据**上报告，真实数据只评根集合；且出自**单篇预印本**，不能代表社区口径 |
| 「EvoCause 与本文 P0 在无环约束上同构」 | **撤回** | 共同使用无环约束是极弱的相似性；边域（任意告警关系 vs 物理邻接）、根假设（多源 vs 单根 Top-K）都不同 |
| 「PropLLM 未处理起点不确定性，是我方可主张的差异点」 | **降为待核实** | 全文检索 `Top-K`/`candidate root`/`single root`/`rank` 均 0 命中——**未提及不等于明确否定** |
| 「调用图时变/长尾说明数据缺失是系统性的、支持 unknown 掩码」 | **撤回** | 时变性与长尾是**结构/负载**观察，**不能确定缺失机制**，也不能替代本项目标签完整度的事实 |

### 6.3 仍然成立的发现

1. **仓库旧材料的三个简称不是正式题名**：COLA、REASON、CORAL 均为系统名，
   其中 REASON 与 CORAL 的正式题名与旧记录完全不同（见 search_log §5.3）。
   COLA 与另存条目实为同一篇，已合并。
2. **「网络侧没有传播关系评价」这一旧概括必须撤回**：NetEventCause 已有事件级局部
   原因关系的 ACC@k 与参考关系对照；APGNN 的题名本身就是「告警传播图」。
   正确表述仍是「未查到与本项目**同粒度、同输出对象**的完整设备 DAG 指标先例」，
   **且该缺口不等于 novelty**。
3. **跨领域存在以路径/图为主输出的工作**：WWW 同级的 CausIL 报 Adj/AH/SHD；
   ASE 的 ErrorPrism 以**路径 exact-match** 评价。这些是**同类输出对象**的对照，
   但它们的指标不与本文的边级 P/R/F1 同口径，**不能直接互换**。

### 6.4 关于 *Complexity at Scale*

该文（arXiv:2504.13141）的摘要支持**结构/负载动态性**的观察（调用图时变、依赖长尾）。
**它能支持的**：不应把长期依赖图当作固定真值。
**它不能支持的**：数据缺失是系统性/非随机的，或本文的 unknown 掩码因此有依据。
本项目标签完整度仍是 **UNKNOWN**（见 `.ai/STATUS.md` B02）。
