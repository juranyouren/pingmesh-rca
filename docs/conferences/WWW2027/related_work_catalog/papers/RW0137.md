## 1. 论文解决的问题

大规模云系统中的**告警风暴**。方法结合**时空关联挖掘**与**对 SOP（标准操作流程）
知识的 LLM 辅助推理**：高置信关联由统计方法处理，低置信关系交由 LLM 分析。
输出为告警关联、同因告警组及解释。

## 2. 与 RPG-Recon 的重叠与关键差异

- 已被本项目列为**告警聚合方向的中心工作**。
- **完整方法需要真实 SOP** —— 这是重要的输入条件差异。仓库选型结论：
  当前保留为相关工作；**有 SOP 时可补告警关联实验**，
  且**不能将聚类直接当作有向 DAG**。
- 其 baseline 集合（AlertStorm、iPACK、DBSCAN、FP-Growth）可作为现成对照表参考。

## 3. 可能的审稿质疑（对我方）

1. 「COLA 已经用 LLM + SOP 做告警关联，你为什么要做图？」
   ——告警关联/聚类不给出**方向**；我方输出的是有向影响关系。
2. 「你没有 SOP，是否说明你的方法在信息更少的情况下反而不公平比较？」
   ——需明确双方输入条件差异，不做「同信息量」的错误声明。
