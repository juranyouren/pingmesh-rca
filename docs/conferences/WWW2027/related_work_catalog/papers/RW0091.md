## 1. 从题名与线索可确认的信息

输出对象是**自动学习得到的加权事件因果图**（weighted event causal graph），
并以此为微服务 RCA 提供可解释性。

**与本项目的输出对象同类**：都是「事件之间的关系图」，且强调可解释。
「加权」这一点值得注意——我方输出边是定性的支持关系，不声称是校准因果概率。

## 2. 与 RPG-Recon 的重叠

- 输出对象同为**事件因果图**（对应我方的事件依赖层）。
- 关注可解释性，与我方要求「每条输出边可追溯到证据引用」同向。
