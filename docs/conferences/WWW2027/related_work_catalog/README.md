## 3. 字段说明

`catalog.csv` / `catalog.xlsx` 的 `Papers` 表为宽表，靠前的是选题用的核心字段。
完整字段分组：

| 字段组 | 列 |
|---|---|
| 引用身份 | `paper_id`、`完整题名`、`简称`、`全部作者`、`DOI` |
| 发表信息 | `venue 全称`、`类型`、`正式年份`、`CCF 等级`、`CCF 目录版本`、`CCF 说明` |
| 访问 | `官方页面 / DOI`、`开放全文`、`代码`、`访问状态` |
| 研究定位 | `层次`、`场景`、`主题标签`、`论文自身输出对象（未逐篇核实）`、`与本文关系（检索线索，未逐篇核实）` |
| 核验 | `身份核验来源`、`身份核验状态`、`核验路径`、`内容阅读深度`、`最后核验日期`、`发现来源`、`候选ID` |
| 原文文本 | `摘要`（取自已核实来源，未改写） |

### 3.1 关键状态字段怎么读

**`身份核验状态`**
- `已核实` —— 有一手来源（Crossref DOI 记录 / 出版方页面元数据 / arXiv abs 页）确认该条目。
- `待核实` —— 未能用一手来源核准，**只出现在 `screening.csv`，不在 `Papers`**。

**`核验路径`**
`doi`（DOI 直取）· `doi-adjudicated`（人工裁定）· `title` / `query.title`（题名检索）·
`page` / `page-curl`（出版方页面元数据）· `arxiv`（arXiv abs 页）。

**`内容阅读深度`** —— **这是本目录最需要留意的字段**
- `摘要已读（来源）；全文未逐节阅读` —— **47 条**。
- `仅元数据（本轮未取得摘要，未阅读正文）` —— **259 条**。

> **大多数条目本轮只核验了身份与著录，没有读正文。**
> 因此 `论文自身输出对象` 与 `与本文关系` 两列的取值来自**检索线索**，
> 已在列名中标注「未逐篇核实」，**不能当作原文事实引用**。

**`CCF 等级`**
- `A` / `B` / `C` —— 取自 **CCF 第七版**（官网发布 2026-03-31），
  由官方目录 PDF 的 dblp URL 条目锚定解析（597 条）后按 venue 名称映射。
- `不适用（预印本）` —— 预印本不继承任何会议等级。
- `不适用（Companion/Workshop 等非正式论文轨道）` —— 目录只计 full/regular paper，
  故 Companion/Workshop/Poster **不继承主会等级**；主会等级写在 `CCF 说明`。
- `未收录` / `待核实` —— 分别表示官方目录无此条目、以及本轮未能定位到条目。

**`访问状态`** —— 注意：**DOI 可解析不等于全文可读**。
本列只说明 DOI 能取到 Crossref 记录；全文可读性**未逐篇验证**。

## 4. paper_id 与去重

- `paper_id` 形如 `RW0001`；待核实条目为 `RX0001`。
- ID 在**建表时按（层次 → 主题 → 年份 → 题名）确定性排序一次性分配**，
  **分配后不随检索或排序变化**。新增条目追加在末尾，不改动既有 ID。
- `候选ID` 列保留流水线内部的候选编号，便于回溯合并前的来源。
- 去重：先用 **DOI**（小写归一），再用**规范题名**。
  预印本与正式版**只有在解析到同一 DOI 时才合并**；否则并列并在 `题名说明` 记录版本关系。

## 5. 使用建议

1. **选题先看 `catalog.xlsx` 的 `Venues` 表**：按 venue 聚合，快速定位每个会刊
   在本目录中的条目数与其 CCF 等级。
2. **核对某条能否引用**：先看 `内容阅读深度`。若为「仅元数据」，
   引用前必须自行读原文；`与本文关系` 一列不足以支撑论断。
3. **本文 novelty 表述前**，先读 `coverage_report.md` §6：
   其中列出了三篇**直接挑战本文贡献**的工作（PropLLM、EvoCause、NetEventCause）
   与两条必须撤回的旧概括。
4. **优先精读**：[papers/](papers/) 下的 12 张阅读卡，每张注明了证据深度，
   并区分「已核实的原文事实」与「研究者判断」。

## 7. 维护方式

1. 新条目追加到 `catalog.csv`（分配新的 `RW` 号），同步更新 `index.md`、`evidence.md`。
2. `catalog.xlsx` 由脚本重建，**不手工编辑**（否则下次重建会覆盖）。
3. 补到全文后，更新对应 `内容阅读深度` 与 `papers/<paper_id>.md`。
4. 发现旧记录错误时，在 `evidence.md` 的「题名差异与旧材料更正」一节追加记录，
   保留原位置与新来源。
