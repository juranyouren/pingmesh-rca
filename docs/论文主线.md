# 论文主线：从旁证观测到异构故障传播图

## 1. 研究动机

Pingmesh 能及时发现哪些源端与目的端之间出现丢包或时延异常，但它观测到的是端到端症状，而不是网络内部的故障发生与传播过程。传统的嫌疑设备排序可以缩小排查范围，却无法回答三类更关键的问题：为什么该设备是根因、异常如何传播到其他设备、各条告警和日志如何支撑这一判断。

运维人员真正缺少的不是另一份设备排名，而是一张能够连接“根因—中间设备—告警事件—Pingmesh 症状”的可核验证据图。因此，本文的主要任务不是单独进行根因排序，而是从拓扑、时间、告警语义和设备归属等旁证观测中，重构一张全局一致的异构故障传播图，并在图中同时识别根因。

## 2. 任务性质

原始观测无法直接给出传播真值。拓扑上下游只说明传播可能性，时间先后不等于因果先后，告警语义可能重复或缺失，设备上的多个事件还可能来自并发故障。由此产生三个相互关联的科学挑战：

1. **Latent Propagation Inference from Circumstantial Evidence**：只能依靠不完备、非决定性的旁证推断潜在传播关系；
2. **Globally Consistent Reconstruction from Locally Uncertain Relations**：局部关系可能矛盾、成环或彼此断裂，需要在全局约束下统一选择；
3. **Identifiability under Observational Equivalence**：多个根因与传播图可能对现有观测具有近似相同的解释能力。

因此，合理的系统不应把每一条局部预测直接当作因果边，也不应被迫输出唯一而确定的答案；它应先保留关系概率，再利用全局传播结构选择解释，并显式报告替代假设和不可辨识性。

## 3. 核心方法

本文在同一张告警—设备异构图上完成根因识别与传播图重构，方法由三个模块组成：

- **M1：证据建模与候选异构子图圈定。** 将告警和日志归一为可追溯事件，结合 Pingmesh 端点与原始 `task_topo`，构建设备、事件和症状节点及其物理、归属和观测关系；
- **M2：异构关系学习。** 通过关系感知图网络输出设备/链路的根因势能、设备对之间的三分类传播概率，以及事件对之间的三分类演化/依赖概率，得到允许局部矛盾和不确定性的概率图；
- **M3：根因—传播图联合重构。** 在原始拓扑合法、单向选择、根可达、无环、症状覆盖和证据一致等约束下，同时选择根因、设备传播 DAG 和事件解释关系，并保留近最优替代图。

其中，设备到设备的有向 DAG 是主要传播结果；事件到事件的关系用于解释异常演化；设备与事件之间的归属/观测关系用于将推断落到原始证据上，而不被误认为传播边。

## 4. 论文的核心论点

本文的关键论点是：**局部旁证不足以独立确定传播关系，但大量局部关系所构成的概率图，可以在传播 DAG、根可达和证据覆盖等全局结构约束下，恢复出更合理且可核验的故障解释。**

根因定位并非与路径重构相互独立的前置任务。根因是传播图中的源变量，而传播图又为根因提供全局解释。因此，在目标设置中二者应联合推断；已知根因的 Oracle 模式仅用于隔离和评价传播图重构能力。

## 5. 预期贡献

1. 将 Pingmesh 诊断形式化为基于旁证观测的异构故障传播图重构，而非单一设备排名；
2. 设计同时建模设备传播、事件演化和证据归属的候选异构图，以及根因势能与局部三分类关系的联合学习方法；
3. 设计带拓扑、可达、无环和症状覆盖约束的根因—传播图联合解码方法，将局部不确定关系转化为全局一致解释；
4. 通过近最优替代图、概率校准和 abstention，刻画观测等价条件下的不可辨识性，避免输出虚假确定性。

## 6. 实际价值

最终传播图不仅指出“最可能坏在哪里”，还说明异常如何从根因影响到 Pingmesh 端点、哪些设备和事件构成证据链、哪些关系仍存在歧义。它可以支持故障排查、修复后的影响链复核，以及对未恢复节点和症状的持续观察，使 Pingmesh 异常从一个需要人工调查的告警，转化为一个可解释、可排查、可验证的故障事件。
