# 论文实验脚本说明

所有活动实验入口位于 `scripts/`，并从 `scripts/common.sh` 读取路径、模型、
NPU 和 Top-K 配置。历史实验位于 `archive/experiments/`，不再作为运行入口。

## 运行顺序

### 1. 确定性排序消融

```bash
source scripts/common.sh
./scripts/run_paper_01_skill_ablation.sh
```

比较 topology、temporal 和融合排名，以及人工/LLM 告警权重。

### 2. 安全门控

```bash
./scripts/run_paper_02_gate_routing.sh
```

固定执行 `pipe → policy search → apply → recall assertion`，输出策略比较、
最终配置、门控覆盖率和不安全 bypass 检查。

### 3. LLM 仲裁

```bash
./scripts/run_paper_03_llm_arbitration.sh
```

比较确定性结果、全量本地 LLM 和安全门控后的本地 LLM。该实验复用步骤 2
选出的策略，不再单独运行旧 gate-policy wrapper。

### 4. 候选摘要消融

```bash
./scripts/run_paper_04_summary_ablation.sh
```

脚本先生成候选节点摘要缓存，再比较全量缓存 LLM 与门控缓存 LLM。已有缓存时：

```bash
./scripts/run_paper_04_summary_ablation.sh --reuse-cache
```

### 5. 基线

```bash
./scripts/run_baselines.sh
```

统一运行 TraceRCA、NetEventCause 和当前 BiAn Pipeline1。

## 主入口

需要自定义实验组合时直接调用：

```bash
PINGMESH_EXPERIMENTS="pipe gate_auto pipe_llm gate_llm" \
  ./scripts/run_rca_experiments.sh my_run
```

支持的实验名只有：`pipe`、`gate_auto`、`pipe_llm`、`gate_llm`、
`cache_llm`、`gate_cache_llm`。未知名称会立即失败，避免旧参数静默生效。

## 主要结果

| 研究问题 | 入口 | 主要产物 |
| --- | --- | --- |
| 排序模块贡献 | paper 01 | Top-1/3/5 与消融汇总 |
| 门控安全与覆盖率 | paper 02 | selected policy、error recall、unsafe bypass、coverage |
| LLM 准确率/成本 | paper 03 | 全量 LLM 与 gated LLM 对比 |
| 摘要缓存价值 | paper 04 | cache LLM 与 gate+cache LLM 对比 |
| 基线对比 | baselines | TraceRCA、NetEventCause、BiAn Pipeline1 指标 |
