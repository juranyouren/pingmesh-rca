运行环境：Windows、Python 3.12.10、PyTorch 2.14.0+cpu、NumPy 2.5.3、pytest 9.1.1。使用公共独立环境 `tmp/baselines-venv`，没有修改系统 Python 包。

执行：

```powershell

```

实际结果：**15 passed in 19.69s**，无警告。

| 验收项 | 证据与范围 |
|---|---|
| 常数强度 NLL | 与完整 5 秒区间解析积分一致；包括首事件前及末事件后；空事件窗口也有生存项 |
| 似然梯度 | 对 log rate 的梯度等于解析表达式；正则为零的配置单独核对 |
| 连续时间积分 | 隐藏态含事件跳变的指数强度，与解析积分对照；减小 RK4 步长使误差收敛 |
| 空历史正则 | 时间及循环更新位置保留，输入嵌入置零；核对全类型平方项及总损失权重 |
| 未来与同时事件 | 改变当前/未来输入嵌入不影响更新前强度；同时事件共享过去强度 |
| IG 数值完整性 | 带符号归因和与 actual−baseline 对数强度差吻合；非法非过去历史被拒绝 |
| 参数/先验与标签 | 先验只来自训练计数与时长；替换测试根/边标签不改变原生输出；检查点恢复输出一致 |
| 未知类型及静默设备 | 不扩充词表、不赋根概率 1；全设备保留；null 与弃权状态可区分 |
| 截止时间 | 晚于截止记录的告警不进入历史，排除原因可追溯 |
| A→B→A 事件机制方向 | 实际 ODE-RNN 人工设置为单调激励后，产生 e0→e1→e2；设备映射暴露 A↔B 折叠环，原生层未提前删边 |
| 事故组隔离 | 训练/验证组交集导致失败；不继续拟合 |
| 失败重训 | 失败后模型不可发布旧结果或半训练状态 |
| 数值异常 | 未拟合预测明确失败、超 ODE 预算明确拒绝、超过 1 的根比值原样保留并诊断 |
| 实际训练 | 合成输入上真实执行 Adam/反向传播，NLL 与总损失下降 |
| 独立 CLI | 子进程完成训练、检查点保存/加载、原生图推理；输入非法的 case_id 仍有 input_ineligible 记录 |

A→B→A 验收人工设置模型参数只用于检验实现方向，**不表示通过训练恢复出了该因果链**。训练损失下降同样不代表根定位或传播图准确率。未知类型、训练规模、观察覆盖、左截断、同时事件顺序、RK4/IG 精度仍须在训练/验证侧审计。

未验证：作者完整模型数值等价、IMOC 原数据结果、真实事故分组交叉验证结果、NPU/GPU 执行、大规模时延，以及与公共适配器结合后的全套 Root/Oracle/Full 实验。公共适配器及评测的集成验收由 A0 负责。
