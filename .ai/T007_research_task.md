**T007 — 调研故障传播图及相关图重构论文，为 RPG-Recon 的图评价指标选择提供可核验的文献依据。**

更新：2026-09-13。执行：Claude Code；验收：Work / 用户。
状态：**READY — 任务已发布，调研尚未执行；最终指标待用户精读后确定。**

用户目的：“我的主要目的是给我的论文有依据地确定下图评价指标。”
用户已接受网络优先、覆盖微服务和通用因果图学习的检索范围。
本任务应帮助用户看清代表论文做什么、怎样评价图、为什么某个指标适合或不适合本论文，
进而自行挑选重要论文阅读，确定一两个主指标。

# 研究对象与决策边界

- 当前对象：一次事故中的单设备根、设备级有向传播解释 DAG。输入为 Pingmesh 异常、
  原始拓扑、设备告警/日志；节点身份有具体设备含义，边表达本次事故的直接影响假设。
- 物理拓扑、服务依赖图、事件图、跨事故统计因果图与事故传播图应区分；可以借鉴邻近任务，
  但说明节点、边、时间尺度及输出语义如何对应，不能因都叫 graph 就视为同一任务。
- 当前不声称恢复真实 ECMP 逐包路线、已识别的完整结构因果模型或干预效果。
- 区分给定共同根后的图恢复与包含预测根的完整流程；根定位质量不自动证明图结构正确。
- 当前人工图标签的完整度、来源独立性及多个可接受解释的比例为 UNKNOWN。
  按“完整图标签”和“部分关系标签”分别讨论适用条件；若存在多个可接受解释，额外说明限制。
  该未知不阻塞文献调研，不先要求用户或工程师补齐数据，也不擅自解释 possible/unknown。
- 旧[指标调研与最终评价方案](../docs/conferences/WWW2027/故障传播图指标调研与最终评价方案.md)
  和 [PROJECT](PROJECT.md) 中的指标组合是已有设计与检索线索。本轮重新核查选取依据，
  不把其中“冻结/主指标”的文字当作用户本次已定案；运行协议、代码和历史结果保持原状态。
- 最终可给少量、有条件的候选建议，但主指标由用户读论文后确定。不得按已有模型得分高低
  或现有 evaluator 恰好支持哪些指标筛选证据，也不以顶会采用本身代替适用性论证。

# Scope 与检索方法

## 范围与优先级

以执行日为检索截止日，近期范围默认 2021 年至执行日；必要的经典工作和指标来源不限年份。
网络、系统领域优先，微服务故障诊断及通用图结构/因果图恢复用于补充可迁移的评价方法。
不限定 WWW，也不延续 T006 的 Web 关联论证任务。

| 类别 | 入选标准 | 本轮作用 |
| --- | --- | --- |
| A：直接相关应用论文 | 重构或推断故障传播/事件影响结构，并直接评价节点、边、方向、路径或整图质量 | 最优先，说明实际传播任务怎样评价图 |
| B：通用图恢复及指标论文 | 提供可迁移的结构评价方法或分析其性质，可能使用合成图/因果图 | 补充指标定义、错误含义及前提，明确领域距离 |
| C：背景对照 | 构图用于 RCA/诊断，但实验仅评价根因排名或下游任务 | 单独列为背景，不能充当图重构质量的直接文献依据 |

正式论文优先核查 CCF A 类会议/期刊，强相关的 B 类工作可以补充。
核对所用 CCF 目录版本和官方分类来源；目录未收录者写“未收录”，不得自定 A/B。
会刊级别、正式发表状态、Research/Industry/Workshop/Companion 等轨道分别记录；
CCF 对会议的分级不能不加说明地套给同名 Workshop。预印本标为补充来源。
不以影响因子、引用数或出版社名称替代会刊级别，也不为查级别扩成排名研究。

目标约 8–12 篇有信息价值的正式论文，其中 3–5 篇作为重点精读候选；
A/B 类构成核心，C 类简表单列，不用于凑核心篇数。
篇数是目标而非硬配额，直接相关证据有限时说明实际范围及缺口。
代表性根据任务接近程度、指标证据完整度及提供的评价维度判断，避免相似论文重复堆叠。

## 执行方式与来源

- 围绕 fault/failure propagation graph reconstruction、alarm/event propagation graph evaluation、
  microservice causal graph structure evaluation、directed graph recovery metrics 等概念分组检索；
  从高相关论文的引用及后续工作定向追踪，记录检索日期、查询、来源和主要排除原因。
- 发表信息用会议/期刊官网、正式 proceedings、出版社页面核查；论文内容优先正式全文，
  可用作者公开稿或机构仓库版本，但记录版本和与正式论文的对应关系。
- 对“某论文使用某指标”的结论，必须有正文或附录的定义/实验定位。
  摘要、二手综述、搜索片段及第三方库的指标列表不能证明原论文实际采用了该指标。
- 作者代码可补充论文未交代的实现细节，须单列代码来源/版本，并区分“论文明确报告”与
  “从作者实现读取”；不能只看 import 或指标函数存在就认定实验使用。
- 指标出处不必追索到最早发明者；优先寻找可靠定义和代表性实际使用证据。
  找不到全文或细节未报告时写明，关键缺证论文不进入已核实精读推荐。
- 优先复用现有全文，缺文再定向获取；记录有限次获取尝试，不因个别访问失败停下可继续的工作。
  原始全文/缓存按既有忽略目录管理，报告中保留来源和定位，避免大段复制原文。
- 延续用户既有执行约束：程序、批量下载/PDF 转换及后续实验在服务器运行；本地可做
  文档协作与现有资料阅读。无需为文献任务启动训练、模型服务或新依赖环境。

# 核心工作一：论文对照与精读卡

先给用户一张可用于挑选阅读的论文总表：

| 字段 | 必须回答 |
| --- | --- |
| 身份与级别 | 完整题名、作者、年份、venue、轨道、CCF 级别及版本、正式论文页和可读全文 |
| 工作概述 | 用 2–4 句说明问题、输入、主要方法与输出，避免仅复述摘要术语 |
| 图是什么 | 节点/边含义、方向、时间尺度；图是事故输出、学习目标还是辅助结构 |
| 原文评价什么 | 图结构指标的原名及中文解释；仅报 RCA/下游指标时明确标注 |
| 可核验证据 | PDF 版本、页码、章节及公式/表/图号或可检索短锚点 |
| 参考图与设置 | 真值来源、完整/部分标签、合成/注入/生产、给定根/预测根或不适用 |
| 关联与阅读价值 | A/B/C 分类、对本项目可借鉴之处、主要不可迁移条件 |

3–5 篇重点候选再做简短精读卡，其余保留有证据的总表条目即可。
每张重点卡补充：

1. 原文图指标的定义/必要公式、评分对象及关键计分约定；原文没交代的写“未报告”。
   区分直接边与可达关系、是否计方向、固定节点身份与自由节点匹配、DAG 与等价类。
   若涉及反向边代价、归一化、宏/微平均、时间滞后折叠或阈值，说明影响解释的差别。
2. 真值怎样获得，标签是否独立于被评方法和构图规则；故障注入给出根标签并不自动给出
   每条传播边真值。缺少独立性说明写 UNKNOWN，不能推断存在或不存在泄漏。
3. 指标能够检验哪一项图恢复假设，漏边、反向、断链、额外分支等错误会怎样被反映，
   哪些错误可能仍获得高分。论文事实与本项目分析明确分开。
4. 对本项目是“可直接采用 / 需满足条件或适配 / 仅作背景 / 不适合当前主张”，附具体理由。
5. 推荐阅读的章节与顺序理由；推荐的是读什么及为什么，不能因 venue 高就默认优先。

不要求复现算法或重跑其数据；没有必要摘录论文所有性能数字。

# 核心工作二：形成可用于论文选指标的依据

在论文证据整理后，归纳少量候选指标（通常 3–5 个，不预设名单），给出对照：

指标及定义来源 → 哪些代表论文实际采用 → 检验哪项图重构主张 → 需要什么标签/图语义 →
能反映和遗漏哪些错误 → 本项目能否采用及需要补什么条件。

必须完成以下判断：

- 分清图结构正确性、约束合法性、证据可追溯性、根因定位和人工排障收益。
  合法 DAG、症状覆盖率或根 Top-K 不能单独证明传播关系恢复正确；
  图结构分数也不能直接证明已识别干预因果关系或降低 MTTR。
- 完整图标签与部分标签分别分析。未标边不自动当负例；多个可接受解释不简单并为唯一真图。
  说明一个指标在部分标注上能支持什么有限结论，无法评价时明确写不适用。
- 比较指标的互补性与冗余，尤其局部关系和多跳/整体结构是否在回答不同问题。
  用 1–2 个小型、可手算的图例说明关键差别即可；注明为解释性例子，不作为实验结论。
- 对最有希望的指标给出清晰的定义及必要计分约定；自拟变体或组合单独标注“本项目建议”，
  不冠以某论文原始指标之名，不无依据宣称某项指标是顶会通行标准。

最后提供至多两套条件化候选组合，每套含 1–2 个主指标，明确：

1. 支撑本论文哪项具体主张；
2. 文献使用依据与本项目语义匹配依据分别是什么；
3. 两指标为何互补（如只有一个也可说明）；
4. 完整/部分/多解释标签下哪些条件满足才可用，当前哪些仍 UNKNOWN；
5. 最有力的一条审稿质疑和结论边界。

给每套方案附一小段可供后续论文写作改写的“选择理由草稿”，引用核实论文，
保留条件语气，不写成指标已选定或实验已完成。
如有必要的辅助诊断仅简要列出，不把“一两个主指标”膨胀为十余项必报协议。
用户尚未精读或定案不影响本调研完成；交付后把“文献工作完成”和“最终指标待用户决定”分开。

# Acceptance Criteria

1. 用户能从报告中判断每篇代表论文做什么、图是什么、用了哪些评价指标、发在哪及何种级别，
   并据此选出要读的论文；重点 3–5 篇附具体推荐阅读位置与理由。
2. 核心引用均回到可读一手全文；指标使用、定义与发表信息可按所给链接和定位复核。
   核实事实、未报告细节、分析者建议彼此可区分。
3. A/B/C 分类清楚；仅评根因排名或下游效果的工作不充当直接图质量依据；
   不为凑数量降低证据质量，实际未覆盖的范围如实说明。
4. 重点指标的图语义、真值来源、标签完整度与实验设置已说明，能判断迁移前提。
   不将未知标签视为负例，也不以同源规则验证自动证明图正确。
5. 候选组合有“文献依据 + 本项目适用性 + 互补性 + 局限”，能支撑后续论文中的选择理由；
   最终选择仍留待用户精读，旧方案没有被未经核验地复制为本轮结论。
6. 项目缺少完整标签/现场数据不阻塞文献交付；条件未知时给条件化判断，不编造已满足。
7. 产物、来源与交接可对应；检查新增/修改文档的本地链接与 UTF-8 编码即可，
   不运行项目测试、论文复现、数据审计、重评分或新实验。
