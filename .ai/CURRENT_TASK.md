## 1. 目标与授权

建立供 RPG-Recon 后续添加参考文献、挑选精读论文和检查相关工作遗漏使用的长期文献对照表。
用户明确要求包含文章名、会议/期刊名、等级、发表时间、访问链接，并尽可能全面。

这是文献目录建设任务，成功标准是相关文献的覆盖、身份准确性、来源可追溯性与后续维护便利性。
不以少量代表论文综述代替目录，不限定必须凑足某个篇数，也不能在已有 baseline 名单处停止检索。
本任务可直接执行，不再要求用户逐项确认检索式、论文名单或常规收录判断。

## 5. 检索策略与执行步骤

### P1：种子与检索矩阵

整理现有论文线索、简称与完整题名，建立稳定 paper_id（如 RW0001，分配后不随排序改变）。
初始种子包括 Pingmesh、deTector、NetBouncer、SkyNet、COLA、NetEventCause、NetCause、Hawkeye、
BiAn、RCACopilot、TraceRCA、REASON、CORAL、PCMCI+、DYNOTEARS、TCDF 等；均待独立核验。
建立“主题 × 场景 × 来源 × 年份”的覆盖矩阵，先保存检索计划，再持续记录实际执行状态。

主题检索按组合拆开运行，不用一个过长 AND 查询限制召回。示例词组：

- 场景：network / datacenter / data center / cloud / microservice / distributed system / RDMA。
- 任务：fault localization / failure diagnosis / root cause analysis / alarm correlation / alert aggregation。
- 输出：fault propagation / failure propagation / causal graph / event dependency / provenance / propagation path / graph reconstruction。
- 中文：网络故障定位、根因分析、告警关联、故障传播图、事件依赖、数据中心诊断。

同时使用简称、完整题名、作者系列工作及同义词，避免遗漏不使用 propagation graph 表述的近邻。

### P2：多来源发现与会刊补查

至少使用两种可用的独立发现渠道，结合综合学术索引和正式 proceedings/出版社检索。
可用 DBLP、OpenAlex、Semantic Scholar、Google Scholar 等发现线索；受限时记录并换用可访问来源。
身份核验优先 ACM DL、IEEE Xplore、USENIX、正式会议/期刊页面；全文可用作者或机构公开稿。
预印本以 arXiv 等版本记录核验。搜索摘要和第三方综述仅作线索，不当作全文能力证据。

网络/系统会刊优先逐年补查：SIGCOMM、NSDI、INFOCOM、CoNEXT、IMC、USENIX ATC、EuroSys、
SIGMETRICS，以及 ToN、TNSM、TMC、TPDS 等相关期刊。
相邻及方法领域按主题补查 WWW/The Web Conference、KDD、ICSE、FSE、ASE、SIGMOD、VLDB、
AAAI、IJCAI、NeurIPS、ICML、ICLR、UAI、AISTATS，以及 TKDE、TNNLS 等期刊。
这是初始来源清单，不是穷尽列表，也不是等级声明；引文发现其他相关会刊时补充。
网络/系统重点来源按 2015 至截止年记录年份覆盖；尚未举办或 proceedings 未公开记“不适用/未公开”，
访问失败记“受限”，不能记为“已查无结果”。相邻领域可按跨年主题查询，但披露粒度和缺口。

### P3：前后向引文扩展

对 L1 核心及跨领域强近邻进行参考文献回溯与后续引用追踪；综述用于补充分类和漏项。
每轮记录起始论文 ID、新增候选、新增纳入及排除原因。新发现的核心近邻继续扩展。
对 2024 年至截止日的新工作另做补漏，包括预印本是否已有正式版本，不用引用量过滤新论文。

### P4：核验、去重与相关性判断

1. 先用 DOI 去重，再用规范题名、作者与版本关系辅助；不能仅按简称合并。
2. 同一工作的预印本与正式版合并为一条主记录，保留全部版本链接与日期；期刊实质扩展版可单列并互链。
3. 核准完整题名、作者、venue、track、年份、日期和 DOI；日期只精确到来源支持的粒度，不编造月日。
4. CCF 等级以执行时核准的官方目录为统一口径，记录版本/领域/来源/核验日期。
   未收录、待核实、不适用分别填写；等级属于 venue，Research/Industry/Workshop/Companion 单独记录，
   不给预印本或 Workshop 自动继承主会等级。必要时说明轨道对应范围不明确。
5. 访问链接优先 DOI/正式页面，另给合法开放全文；验证链接与目标论文一致。
   区分正文可读、仅摘要、付费、失效和未检查，不以 DOI 可解析代表全文可读。
6. 对相关性、原始输出和新颖性威胁提供证据位置，原文事实与研究者判断分栏。

### P5：覆盖审计与停止条件

完成重点会刊年份补查、全部现有种子处理、近期补漏及核心引文扩展。
连续两轮完整引文扩展无新的 L1 核心近邻，可作为停止依据之一；它不替代其他覆盖检查。
不以总篇数、搜索排名前 N 条或耗时作为全面完成的证明。来源受限时交付已核实结果、具体未覆盖项
及替代检索尝试，结论写“已完成可访问范围，仍有缺口”，不能宣称绝对穷尽。

## 6. 文献表字段与证据规则

| 字段组 | 必填内容 |
| --- | --- |
| 引用身份 | paper_id、完整原文题名、全部作者、简称（无则留空）、DOI（不存在/未核到分别说明） |
| 发表信息 | venue 全名与缩写、会议/期刊/预印本类型、track、发表状态、正式年份、在线发表日期、卷期页码或文章号（适用时） |
| 等级 | CCF A/B/C/未收录/待核实/不适用、目录版本、领域、官方来源、轨道适用说明 |
| 访问 | 官方页面/DOI 链接、开放全文链接、代码链接（有则记录）、各访问状态、版本关系 |
| 研究定位 | L1/L2/L3、主题标签、场景、问题简述、输入、输出、与本文的关系及关键不同条件 |
| 核验 | 身份核验来源、内容证据定位、身份核验状态、内容阅读深度、最后核验日期、发现来源/检索记录 ID |

题名、venue、等级、发表时间、访问链接放在总表靠前列，便于用户直接选文献。
允许宽表提供完整字段，Markdown 索引保持紧凑并通过 paper_id 链接证据。
身份已核实但全文受限的相关论文可纳入，内容写“仅摘要/待全文核实”，不写未经核验的能力断言。
身份冲突或相关性待判定的候选放 pending；已排除候选保留题名/链接/理由，避免下一轮重复筛选。
发现旧文献身份或描述错误时建立简短 correction 记录，保留原记录位置、新来源及修正理由。

## 7. 交付目录

在 `docs/conferences/WWW2027/related_work_catalog/` 建立：

1. `README.md`：目录入口、范围、截止日、字段/状态说明、主要统计和使用方法。
2. `catalog.xlsx`：可筛选排序、冻结表头、可点击链接；至少含 Papers、Pending、Coverage、Venues 工作表。
3. `catalog.csv`：与 Papers 一致的 UTF-8 机器可读主表，作为可比较、可增量维护的数据源。
4. `index.md`：按主题/层次组织的简明文献对照表，保留用户要求的五类字段及 paper_id。
5. `search_log.md`：实际查询、日期、来源、年份过滤、访问限制、筛选结果与引文轮次；只记录真实执行。
6. `coverage_report.md`：覆盖矩阵、各层与年份/会刊统计、版本去重数量、未覆盖项、停止依据与后续补漏入口。
7. `evidence.md`：按 paper_id 记录元数据和内容来源/定位、等级出处、冲突修正；表格可链接至此。
8. `screening.csv`：未纳入或待核实线索、来源、状态和具体理由；与 Pending 状态一致。
9. `papers/<paper_id>.md`：核心近邻阅读卡。卡片数量由相关性决定，不预设固定配额；L1 中仅作背景的
   工作可用表格证据覆盖并注明未建卡理由，所有直接挑战本文贡献的工作均须有卡。

阅读卡用中文说明：论文解决的问题、输入与额外观测要求、方法与输出对象、节点/边/时间尺度，
与本文重叠及不同点、可能的审稿质疑、值得精读的章节和来源定位。
若据实验论证贡献，还需记录 hypothesis、数据/故障注入/标签来源、实验有效性、可能泄漏与混杂因素；
未报告写 UNKNOWN，不无证据断言泄漏。区分根排名、图质量与人工排障收益，避免仅抄性能提升数字。

原始 PDF 和提取缓存留在既有忽略位置，不提交到 Git；目录保留可访问链接和版本信息。
不要求本轮建立 Zotero 库或生成 BibTeX；记录足够的元数据供后续引用导出。
只在 WWW2027 相关索引添加入口，不改写正式论文的 related work、baseline 结论或主指标决定。

## 9. 验收标准

1. 用户能在 Excel/Markdown 中按题名、venue、等级、时间、链接直接查找并筛选文献；链接确实指向该文。
2. 既有种子有明确处理结果，三层范围、重点会刊年份、近期补漏和核心前后向引文扩展都有真实执行记录。
3. 所有主表记录有一手身份来源；无法确认的身份进入 Pending，日期、CCF 版本和发表轨道不混淆。
4. 全文阅读深度、访问状态和证据缺口透明；核心能力/贡献比较可回到全文位置复核，二手描述不冒充原文事实。
5. paper_id 唯一且稳定，预印本/正式版去重关系明确；CSV、Excel Papers、分类索引的 ID 集合与核心字段一致。
6. 核心近邻卡解释问题、原始输出、贡献重叠及假设差异；不能以无法复现、输入不同或不利于本文为由漏收。
7. 覆盖报告准确区分“已查无结果”“访问受限”“尚未检索”“尚未公开”；不宣称证明绝对穷尽。
8. 验证文件可打开、UTF-8 正常、表头/筛选/冻结/链接有效、必填字段无静默缺失、重复 ID/DOI 已处理。
   检查 Markdown 本地链接和跨文件数量一致；只做产物检查，不运行项目测试。
9. 任务发布、阶段交付、检索完成和独立验收分别记录；T007-R/T006-R 待办及历史结论保持可追溯。
