## 必须返修的问题

### R1 — 不能用 Web 字频或 CCS 分类替代相关性分析

[synthesis](../docs/conferences/WWW2027/web_relevance/synthesis.md) §2 将 InArt 的 CCS 无 Web 类别
推断为作者未把论文定位为 Web；但 [InArt 原文](https://www.fangjin.site/pdf/inart.pdf) p.1
关键词明确包含 Web Infrastructure，引言给出电商/社交/广告 → 深度学习 → 分布式训练 → 通信瓶颈。
其应用依赖链是实质动机，Web 用户侧收益未测则是另一项证据边界。

同样，MULAN 正文少用 Web 术语，不等于只剩会议归属。
[MULAN §4.1.1](https://arxiv.org/html/2402.02357v1) 包含电商 Online Boutique，
[该基准官方说明](https://github.com/GoogleCloudPlatform/microservices-demo) 明确它是 Web 电商应用。
应区分作者显式叙述、工作负载关联与业务收益验证，不能把后两者由字频直接否定。
DNS 的依赖/可达性也可以是基础设施问题；是否测页面加载不是唯一判据。

**修正要求：**重建分类，分别记录研究对象、应用依赖链、实验工作负载、实际测量指标。
分类无需互斥，不把“去掉 Web 术语后算法仍通用”当作不相关的充分条件。

### R2 — 私有网络不意味着只能靠背景措辞联系 Web

synthesis §3 从内部拓扑私有推到“只能靠领域命名”，推论不成立。
私有部署依赖、受控测试床和应用工作负载同样可以验证网络到服务的联系；
骨干网与 DCN 也不能在“没有公开观测面”上混同，该文自己列举了 MAWI/CAIDA。

**修正要求：**改为“当前项目尚未提供服务映射和应用侧观测”；这是当前资产缺口，
不是 DCN 研究的固有限制。不要把某篇大规模 Starlink 测量的全部设施当作所有强关联研究的必要条件。

### R3 — 工程师指标与 Web 指标是不同维度

[positioning_options](../docs/conferences/WWW2027/web_relevance/positioning_options.md) 方案 B
把检查时间、接受率与诊断决策质量称为 Web 指标绑定，并给出中高相关性，依据不足。
这些指标可证明运维价值，但还需实际 Web 基础设施场景才能支持该相关性。
方案 A 的部署说明是场景证据，不能仅称写作材料；方案 C 也依赖未冻结的标签与评价。

**修正要求：**A 是应用场景，C 是候选科学问题，B 是可选运维评价，三者可组合。
当前建议是条件性的 A+C；业务未知时只保留一般云网络定位。
官方范围允许基础设施研究，但不保证补一份部署说明即可通过 relevance 审查。
禁用外部 LLM API 也不等于不能使用本地 agent；不扩展 agent 的理由应是任务与证据不需要。

### R4 — 综合表丢失了原始实验条件

synthesis §1 将 WiseStart 的生产部署与 First AFT 降低 25.43% 并列，容易误读为生产首屏实测。
[WiseStart 分析卡](../docs/conferences/WWW2027/web_relevance/papers/www24-wise-start/analysis.md) §6
已明确生产评估测 RCT，First AFT 来自仿真，25.43% 是所报告中位数改善区间的上界。
综合表必须保留这些限定。

InArt §5 同时有硬件 testbed 与软件仿真；§5.3 的 1000 倍缩放涉及仿真参数，
不能泛化为全部实验/设备规模缩小 1000 倍。附录 B 的省略说明也不能抹掉 §5 已有性能评估。
这些是实验有效性边界，不能直接用于否定其 Web 定位。

**修正要求：**逐项回填环境、指标、分母/区间及对应页节；删除“唯一有生产部署”等无充分比较依据的断言。

### R6 — 科学性批评和假设应匹配证据

- ODNS 的受控权威 DNS 与唯一 A 记录是测量设计，不能仅因“由作者构造”就判定自证循环。
  只有证明标签取自同一待验证规则且缺独立核验，才能指认循环；否则写成独立验证范围待查。
- 方案 C 的 Oracle 根下 F1 < 1，至多说明当前数据、标签和解码器仍有重建误差；
  不能证明任务固有不可恢复性。P0 距离限制、缺失证据、标注误差需分离。
- unknown 掩码与负例填充改变分母后分数不同，不是算法改善的证明。
- “现有方法多把未观测关系当负例”须逐篇核实训练/评价语义；
  两阶段外形相同不能直接判定技术同构，输出设备图不同也不能单独证明 novelty。
- 部署材料由看过标签的工程师提供不自动构成测试泄漏；需检查材料是否被用于筛例、调参或构造模型输入。

**修正要求：**将因果性/不可恢复性/泄漏指控降到证据允许范围，
保留可检验的控制与替代解释，不用一般质疑代替文献中的实际证据。
